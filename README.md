# FatesNativePublic
A WIP PC Native Interpretation of Fire Emblem Fates. 

This is the public facing repo, expect to be outdated, currently not in a traditional playable state, however extensive headless simulations can be ran and compiled. 

Primitive D3D11 drawing is supported as of this moment (see below), but GPU support is not.
